Introducción a CSS

CSS (Cascading Style Sheets) es un lenguaje de diseño que se utiliza para definir la presentación visual de un documento HTML. Sirve para controlar el color, la tipografía, la disposición y el aspecto general de los elementos en una página web.

Diferencia entre display: none y visibility: hidden: display: none oculta el elemento por completo y elimina el espacio que ocupaba en el maquetado. En cambio, visibility: hidden oculta el elemento de la vista, pero conserva exactamente el mismo espacio físico que ocupaba en la estructura HTML.
